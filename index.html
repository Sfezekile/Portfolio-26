Manual

MyOS Portfolio is a unique, operating-system-inspired portfolio website designed to showcase my skills, creativity, and continuous learning journey. Unlike traditional portfolios, MyOS simulates a desktop environment with windows, taskbars, and file navigation to provide an immersive and memorable experience for visitors.

How It Works

What This Portfolio Represents

Creativity & Innovation

Willingness to Learn

Progress Tracking

Interface Components

1. Desktop Environment

  • Wallpaper: Custom background creating OS atmosphere
  • Interactive Elements: Clickable desktop icons (planned feature)
  • Responsive Design: Adapts to different screen sizes

2. Menu Bar (Top Bar)

  • User Name: Personal branding element
  • System Clock: Live time display updating every 30 seconds
  • Status Icons: Network, volume, and battery indicators (visual only)

3. Taskbar (Bottom Bar)

  • Start Menu: Click to reveal user menu (functional design)
  • Application Icons: Quick launch buttons for:
    • File Finder (file explorer)
    • Browser (web browser simulation)
    • GitHub, VS Code, MySQL Workbench, Figma (external links - planned)

4. Window System

  • Draggable Windows: Click and drag any window by its header
  • Window Controls:
    • Minimize: Hides the window
    • Maximize: Expands to full screen
    • Close: Closes the window
  • Resizable: Drag edges to resize windows
  • Z-Index Management: Windows stack properly when clicked
